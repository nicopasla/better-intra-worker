# Better Intra Worker

Backend 'cloud' worker for Better Intra extension, managing user synchronization and persistence via Cloudflare KV and D1.
Automated deployment through GitHub Actions.

## Commits

Conventional Commits, single subject line (`type(scope): subject`), no body — see the root `AGENTS.md` of the better-intra repo for types and scopes (use the `worker` scope here).
